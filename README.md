# Gams

Offline games that work without internet connection.

## Quick Start

1. Download and extract the repository
2. Open `Gams.html` in your browser
3. Choose from a variety of games including Flash games

## Features

- Dark and light mode
- Customizable title and favicon
- Works offline (Chromebook and Windows)
